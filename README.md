# موقع Portfolio شخصي

موقع شخصي لطالب برمجة يعرض: نبذة عني، السيرة الذاتية، المهارات، ومعلومات التواصل. الموقع باللغة العربية (من اليمين لليسار) ومتجاوب مع الكمبيوتر والأجهزة اللوحية والهواتف.

## التقنيات المستخدمة
- **HTML5** لبناء هيكل الصفحة.
- **CSS3** للتنسيق والتأثيرات (ملف `css/style.css`).
- **Bootstrap 5.3** (نسخة RTL) لنظام الشبكة وشريط التنقل المتجاوب.
- **Bootstrap Icons** للأيقونات.
- **JavaScript** بسيط في `js/main.js` (السنة في الـ Footer، ظل الـ Navbar، إغلاق قائمة الهاتف).
- خطوط Google: Reem Kufi للعناوين، IBM Plex Sans Arabic للنصوص، JetBrains Mono لبطاقة الكود.

## هيكل الملفات
```
portfolio/
├── index.html        الصفحة الرئيسية (كل الأقسام)
├── css/
│   └── style.css     التنسيقات والألوان
├── js/
│   └── main.js       سكربت تفاعلي صغير (ملف إضافي)
├── images/
│   └── profile.jpg   صورتك الشخصية (حاليًا صورة مؤقتة)
└── README.md
```

## أين أضع بياناتي؟
- افتح `index.html` وابحث عن الرمز ✏️ في التعليقات، وعن أي نص بين قوسين مربعين مثل `[اكتب اسمك]`.
- استبدل `your-username` و `your-email@example.com` بحساباتك الحقيقية (استخدم البحث والاستبدال في المحرر: `Ctrl + H`).
- ضع صورتك داخل مجلد `images` باسم `profile.jpg` (يفضل أن تكون مربعة، 400×400 بكسل على الأقل).
- لتغيير الألوان عدّل المتغيرات في أعلى `css/style.css` داخل `:root`.

## التشغيل محليًا
**الطريقة الأسهل:** افتح ملف `index.html` مباشرة في المتصفح (نقرتان).

**باستخدام VS Code:** ثبّت إضافة **Live Server**، ثم انقر بزر الفأرة الأيمن على `index.html` واختر *Open with Live Server*. ستتحدث الصفحة تلقائيًا كلما حفظت تعديلًا.

> ملاحظة: Bootstrap والخطوط والأيقونات تُحمَّل من الإنترنت، لذا يجب أن تكون متصلًا بالإنترنت ليظهر التصميم كاملًا.

## النشر على GitHub Pages
بعد رفع المشروع إلى GitHub: Settings ← Pages ← اختر الفرع `main` والمجلد `/ (root)` ← Save. سيظهر الموقع بعد دقائق على:
`https://your-username.github.io/portfolio/`
